# Interface Destruction — расширение Chrome

Разрушай текущую страницу с помощью 11 видов оружия или трёх техник Сатору Годжо. Буквы отлетают отдельно, панели раскалываются, фон прожигается, а осколки падают и отскакивают. Есть pixel-art модели, космический фон и локальные звуковые эффекты.

Игра работает поверх копии видимой части страницы. Настоящие элементы сайта и значения полей остаются на месте; выход из игры возвращает страницу к обычному виду.

История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Установка

1. Скачай репозиторий через **Code → Download ZIP** и распакуй архив.
2. Открой `chrome://extensions` и включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку репозитория или `dist/` внутри неё.
4. Закрепи **Interface Destruction** в меню расширений.
5. Открой обычный сайт и нажми кнопку расширения.

Готовая сборка включена в репозиторий: устанавливать зависимости и собирать проект для запуска не нужно. При подготовке страницы отображается загрузчик с кнопкой отмены.

После замены файлов нажми **Обновить** на карточке расширения и перезагрузи вкладку сайта.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | A/D или стрелки влево/вправо |
| Прыжок / полёт | Space или W |
| Спуск сквозь платформу | S |
| Стрельба | ЛКМ |
| Граната в обычном режиме | ПКМ |
| Выбор оружия | 1–9, 0, − или колесо мыши |
| Пауза | Esc |
| Запуск / закрытие игры | Кнопка расширения; ⌘ Shift Y на Mac, Ctrl Shift Y на Windows/Linux |

Горячую клавишу расширения можно изменить в `chrome://extensions/shortcuts`. Игра на каждой вкладке работает отдельно; после перехода на новую страницу запусти её снова.

**Выйти и восстановить** закрывает игру. **Восстановить и начать заново** запускает новый раунд.

## Оружие

| Клавиша | Оружие |
| --- | --- |
| 1 | Пистолет |
| 2 | Дробовик |
| 3 | Автомат |
| 4 | Снайперская винтовка с большим пробиванием |
| 5 | Огнемёт |
| 6 | Ракетница |
| 7 | Гранатомёт |
| 8 | Лазер |
| 9 | Ядерная бомба |
| 0 | Пушка чёрных дыр |
| − | Кислотная пушка |

- **Огнемёт** постепенно поджигает элементы и прожигает фон. Огонь виден возле попаданий, а по краям пробоин остаётся тление.
- **Лазер** прошивает экран и вырезает панели и фон по всей линии. При удержании луч расширяется; материал вне луча остаётся на месте.
- **Ракеты, гранаты и гранатомёт** пробивают фон. **Ядерная бомба** создаёт вспышку, ударную волну, огненный гриб и массовые разрушения.
- **Чёрная дыра** летит до выбранного места без столкновений и постепенно поглощает ближайшие элементы, закручивая обломки по спирали.
- **Кислота** медленно разъедает элементы и фон в ограниченной области. Во время полёта снаряда могут падать дополнительные капли; после завершения действия пятен коррозия прекращается.

Кнопка **Запустить дрон** переключает управление на дрон: WASD / стрелки. Он взрывается при столкновении или через 8 секунд. ЛКМ или кнопка **Взорвать дрон** подрывает его вручную.

## Сатору Годжо

Нажми **Режим Сатору Годжо**, чтобы переключить персонажа и арсенал:

- **1 — Синяя:** притягивает ближайшие элементы и обломки прямо к центру.
- **2 — Красная:** энергетический снаряд с ударной волной, пробоиной в фоне и отбрасыванием осколков.
- **3 — Фиолетовая:** один клик запускает слияние энергий, затем одиночный сквозной луч постоянной ширины. Начатый каст не прерывается отпусканием кнопки; направление фиксируется при клике, начало луча следует за рукой до момента выстрела. Выпущенным лучом нельзя водить.

Годжо левитирует. В этом режиме нет гранат и дрона. Кнопка **Обычный режим** возвращает весь арсенал; переключение сохраняет разрушения страницы.

## Звук

Оружие, техники Годжо, полёт и взрыв дрона озвучены локально через Web Audio. Звук включается после первого клика по игровому полю или запуска дрона. Кнопка **Звук: вкл/выкл** управляет озвучкой; на паузе непрерывные звуки затихают, при выходе аудиоконтекст закрывается.

## Доступ к страницам

Расширение рассчитано на настольный Chrome 110+. Использует Manifest V3 и разрешения `activeTab` и `scripting`: доступ к вкладке появляется при нажатии кнопки или горячей клавиши. Автоматического запуска, постоянного доступа ко всем сайтам, аналитики, игрового сервера и удалённого исполняемого кода нет. Спрайты включены в пакет.

Chrome запрещает запуск на `chrome://` и некоторых защищённых страницах, включая Chrome Web Store. В таком случае на значке появится `!` с пояснением. Для `file://` отдельно разреши доступ к файловым URL в настройках расширения.

Захватывается видимая часть DOM главного документа; страница не прокручивается. Содержимое iframe, закрытого Shadow DOM и некоторые псевдоэлементы воспроизводятся не полностью. Меню расширения изолировано от CSS сайта.

## Разработка

- `dist/` — готовая сборка для Chrome; готовые файлы также находятся в корне.
- `manifest.json` — настройки и разрешения расширения.
- `src/background.js` — запуск по кнопке браузера.
- `src/content.tsx` — контейнер игры, запуск и очистка.
- `src/destruction/` — игровой режим, оружие, эффекты и спрайты.
- `scripts/build.mjs` — сборка и копирование ресурсов.
- `AI_INSTRUCTIONS.md` — инструкция для дальнейших изменений.
- `VERIFICATION.md` — результаты и условия проверок.
- `CHANGELOG.md` — история изменений.

```sh
npm install
npm run types-check
npm run build
```

Сборка обновляет `dist/` и готовые файлы в корне. После пересборки обнови расширение в `chrome://extensions` и перезагрузи страницу сайта. Страница помощи доступна через пункт **Параметры** в меню расширения.
